## Overview

SourcePauseTool is a SourceMod plugin that enables frame-perfect pausing, tick-accurate demo recording, and precise entity inspection for runners and TASers working in GoldSrc and Source games.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SourcePauseTool** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Frame Pause** | Advance simulation one tick at a time for TAS and verification |
| **Demo Recording** | Tick-accurate demo capture with custom start and stop triggers |
| **Entity Inspector** | Real-time readout of velocity, origin, and angles for key entities |
| **HUD Overlay** | On-screen timer, tick counter, and split data during runs |
